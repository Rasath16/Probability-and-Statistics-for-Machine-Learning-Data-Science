
# Probability & Statistics for Machine Learning and Data Science – Probability and Statistics

This repository contains my **handwritten notes, slides, and Python notebooks** from the **Probability and Statistics** course in the *Mathematics for Machine Learning and Data Science Specialization* by [DeepLearning.AI](https://www.deeplearning.ai/).

The purpose of this repo is to **share valuable learning materials** and help others build a strong foundation in **probability and statistics**, which are core pillars of **Machine Learning (ML)** and **Artificial Intelligence (AI)**.

---

## 📘 Course Overview

This course explores how probability theory and statistical thinking power modern ML algorithms.
Key concepts covered include:

* Random variables and probability distributions
* Expected value, variance, and standard deviation
* Discrete and continuous distributions
* Joint, marginal, and conditional probabilities
* Bayes’ theorem and independence
* Sampling and estimation
* Hypothesis testing and p-values
* Statistical inference and applications in ML
